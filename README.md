iOS and Android apps delivered end to end, two of them live on the stores, with their API and their infrastructure: Flutter on the client, NestJS on PostgreSQL behind, Docker and Ansible underneath. Used to demanding environments: Paris Police Prefecture, Banque de France, sensitive data and GDPR.
